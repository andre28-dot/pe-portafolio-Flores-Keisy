# Sesión 13

**Funciones de orden superior y callbacks tipados**

Revisa el material teorico de está sesion, lee, analiza y luego responde ¿Por qué conviene utilizar callbacks en lugar de repetir una función completa para cada operación? 

Mi respuesta: Conviene utilizar callbacks porque asi podemos usar una misma funcion para hacer diferentes operaciones sin tener que repetir todo el codigo, lo que hacemos es pasarle otra funcion para indicarle que queremos que realice, de esta manera evitamos escribir lo mismo varias veces y el codigo queda mas ordenado y es mas facil de modificar.
